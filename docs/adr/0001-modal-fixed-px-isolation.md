# 0001 — 设置弹窗使用固定 px 尺寸与固定基准字号

- 状态：已接受（2026-09，随字号滑块抖动修复落地）
- 影响范围：`src/assets/styles.css`（`.modal-mask` / `.modal-card`）

## 背景

全局字号通过 `html` 上的 `--app-font-size` 变量驱动，界面大量使用 `rem` 单位。设置面板的字号滑块会修改该变量：如果弹窗自身尺寸也随 `rem` 缩放，拖动滑块时弹窗几何尺寸随之变化，滑块轨道在屏幕上移动，指针相对位置的改变又反过来改变滑块值，形成布局反馈振荡（拖大 → 弹窗变宽 → 数值回跳变小 → 弹窗变窄 → 数值再变大，无限循环）。

## 决策

- `.modal-mask` 与 `.modal-card` 显式设置固定基准字号 `font-size: 15px`，不随 `--app-font-size` 缩放；
- `.modal-card` 尺寸用固定像素定义（`width: 440px; min-width: 380px; max-width: min(720px, 92vw);`），不使用 `rem`。

## 后果

- 拖动字号滑块时弹窗几何位置恒定，振荡环被切断；背景主界面仍实时响应字号变化作为预览。
- 弹窗内部文字不随全局字号缩放（符合桌面端设置窗口的通用惯例）。
- 新增弹窗直接复用 `.modal-mask` / `.modal-card`，不要重新引入 rem 尺寸。
